Hello World
A simple HTML project that displays Hello World! in a web browser.
Project Overview
This is the first task of the web development course. The goal is to create an index.html file and print the text Hello World! on the screen.
Project Structure
Hello-World/
├── index.html
└── README.md
How to Run
1. Download or extract the project folder.
2. Open the folder.
3. Double-click index.html, or open it in your preferred web browser.
4. The page should display:
   Hello World!
No additional software, dependencies, or server setup is required.
Technologies Used
- HTML5
Expected Output
When index.html is opened in a browser, it displays the text Hello World!.
