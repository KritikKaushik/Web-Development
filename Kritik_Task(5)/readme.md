# Laundry Services Hero Section

## Description
This project is a simple laundry service landing page created using HTML and CSS. It contains a navigation bar and a hero section.

## Features
- Navigation bar with Home, Services, About Us and Contact Us.
- Logo on the left and username on the right.
- Hero section with a heading and description.
- Book a Service Today button.
- Laundry-related image on the right side.

## Technologies Used
- HTML5
- CSS3

## Project Structure
```text
Laundry-Website/
│
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.

## Objective
To design a simple and attractive laundry service hero section using HTML and CSS, following the given assignment requirements.
