Laundry Wallah / Laundry Mart -- HTML Webpage
A simple HTML webpage for Laundry Wallah / Laundry Mart, a laundry
service website. The page introduces the business, highlights its
services, and displays a basic price list in a clean, user-friendly
layout.
Project Objective
Create a foundational HTML webpage that presents the laundry service
online and makes it easy for visitors to understand the available
services and their prices.
Required Sections
1. Header Section
   - Display a welcoming heading: "Welcome to Laundry Wallah /
     Laundry Mart".
2. About Section
   - Add a short introduction (approximately 5--8 lines) describing
     the laundry service.
3. Image Section
   - Insert a relevant laundry image. An image sourced from the
     internet may be used.
4. Services Section
   - Add the heading "Our Services".
   - List the services using an ordered or unordered HTML list.
   - Suggested services:
     - Washing and Drying
     - Ironing and Folding
     - Dry Cleaning
     - Stain Removal
     - Express Services
     - Special Garment Care
5. Price List Section
   - Add the heading "Price List".
   - Create a bordered HTML table with service names and their
     corresponding prices.
   - Include at least two services. Example prices from the task:
     - Washing and Drying -- Rs 10.00
     - Ironing and Folding -- Rs 5.00
Technologies
- HTML5
- Basic HTML elements and attributes
- HTML table, lists, headings, paragraphs, and images
