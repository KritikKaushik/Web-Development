# Task 3 – CSS Units, Box Model and Fonts

## Description
This project is a simple webpage created using HTML and CSS. It contains an image and a button styled using basic CSS properties.

## Technologies Used
- HTML5
- CSS3

## Features
- Basic HTML document structure
- External CSS stylesheet
- Image displayed inside a div
- Button with gradient background
- CSS Box Model
- Viewport units (`vw` and `vh`)
- Basic font styling

## Project Structure
```text
Task-3/
│
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## Learning Outcome
Learned how to use CSS units, box model properties, fonts, spacing and gradient backgrounds to style a webpage.
