# CSS Selectors Task

This task is about learning and practising different CSS selectors using HTML and CSS.

In this task, I created different headings, paragraphs, ordered lists and unordered lists. I used class selectors, ID selectors and element selectors to change text colors, background colors and font sizes.

I also used pseudo-class selectors like `:first-child`, `:last-child` and `:nth-child()` to style specific list items.

The main aim of this task is to understand how different CSS selectors work and how to apply styles without using inline CSS.
